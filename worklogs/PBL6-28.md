## 1. Màn hình

| Route | Vai trò | Nội dung |
|---|---|---|
| `/search` | Khách | Duyệt theo danh mục: breadcrumb, danh mục con, khoảng giá, số sao, sắp xếp, phân trang (state nằm trên URL) |
| `/products/:id` | Khách | Gallery, chọn phân loại theo `attributes`, tồn kho theo phân loại, shop, mô tả, sản phẩm tương tự |
| `/seller/products` | Seller | Bảng sản phẩm, tab trạng thái, tìm tên/SKU, ẩn/hiện, xoá, gửi lại sau khi bị gỡ |
| `/seller/products/new`, `/:id/edit` | Seller | Form: thông tin, danh mục (cây), tối đa 9 ảnh, phân loại (SKU, thuộc tính, giá, tồn kho) |
| Admin › Quản lý danh mục | Admin | Cây nhiều cấp: thêm (cấp 1 / con), sửa, ẩn/hiện, xoá |
| Admin › Kiểm duyệt sản phẩm | Admin | Gỡ (bắt buộc lý do) / khôi phục |

## 2. Backend bổ sung

- `POST /api/products/seller/media` (SELLER, multipart `file`) → `{url}` dưới `products/{sellerId}/`;
  `DELETE ...?url=` dọn ảnh bỏ dở, trả `409 MEDIA_IN_USE` khi ảnh còn gắn với sản phẩm.
- `shared-media`: `ImageKind.PRODUCT` (vừa 1200×1200, JPEG, ≤ 5 MB, không cắt vuông).
- Endpoint đặt dưới `/seller/` để không đụng `GET`/`DELETE /api/products/{id}`.

# Worklog — PBL6-27 ShopUI

## Phạm vi

- Đăng ký gian hàng, trạng thái chờ duyệt / bị từ chối, cài đặt shop.
- Seller dashboard: thống kê thật + đơn hàng gần đây.
- Trang gian hàng công khai.
- Admin duyệt / từ chối / đình chỉ / gỡ đình chỉ.
- Cấp role SELLER khi shop được duyệt (auth-service consumer).

## Quyết định

- District bị bỏ khỏi form; `PUT /me` xoá district cũ.
- Logo/cover nhập URL, không upload.
- Role SELLER cấp async qua RabbitMQ; không revoke khi suspend.
- `deliveredRevenue` chỉ đơn DELIVERED; hiện gần 0 vì chưa có luồng giao hàng.
- Public page ẩn rating/follow/chat/category pills/add-to-cart.
- Dashboard thay 2 KPI không có API bằng sản phẩm đang bán + tỉ lệ huỷ.
- Ẩn nút global "Lịch sử xét duyệt".
- Không dùng `Idempotency-Key` cho shop writes; dựa `uq_shops_owner_id` + 409.
- `range`: `7d` = hôm nay + 6 ngày trước, `30d` = +29, `90d` = +89; `to = now`.
- `grossRevenue` gồm đơn non-CANCELLED; `deliveredRevenue` chỉ DELIVERED.
- Top sản phẩm: top 5 theo quantity, bỏ CANCELLED, tie-break bằng revenue.
- Enrichment owner/actor lỗi downstream → `null`, không làm hỏng response.

## Việc đã làm

### Backend

- `order-service`:
  - `V9__shop_stats_indexes.sql` + index cho `shop_id` / trạng thái / ngày.
  - `OrderStatsService` + `InternalOrderStatsController` aggregate theo `shopId`,
    zero-fill theo ngày, timezone VN, `BigDecimal`.
  - endpoint nội bộ stats + recent orders, xác thực `X-Internal-Api-Key`.
  - `DeliveryMigrationTest` / `FlywayMigrationTest` cập nhật version 9.
- `user-service`:
  - `POST /internal/users/profiles` batch lấy tên/avatar; lỗi/không thấy → null.
  - `InternalApiProperties`, `SecurityConfig` cho internal key.
- `auth-service`:
  - consumer `ShopApproved` trên queue `auth.events.v1`, idempotent, cấp SELLER,
    xử lý cả `reinstated=true`, không revoke khi `ShopSuspended`.
  - `SellerRoleGrantService` + test consumer 4 case.
  - Dockerfile cài parent POM + `shared-events` trước `go-offline` để build image.
- `shop-service`:
  - `GET /api/shops/me/stats?range=...`, `GET /api/shops/me/recent-orders?limit=...`
    (proxy order-service; ACTIVE-only; lỗi downstream → 503 có mã lỗi).
  - `GET /api/shops/admin/counts`.
  - enrich owner/actor qua user-service; response public/danh sách/admin có ownerName,
    ownerAvatarUrl, actorName.
  - `ShopStatsService`, `ShopProfileEnricher`, downstream clients/config
    (`app.downstream.*`, `INTERNAL_API_KEY`).
- `docker-compose.yml`: shop-service có `USER_SERVICE_URL`, order/product URL,
  `INTERNAL_API_KEY`, `extra_hosts`.
- `docs/event-bus.md`: ghi nhận auth consumer + hành vi role SELLER.
- Chạy order-service cục bộ cho dashboard dev (compose chưa có block order-service):
  `cd services && .\mvnw.cmd -pl order-service -am install -DskipTests`, sau đó
  `cd services\order-service && java -jar target\order-service-0.0.1-SNAPSHOT.jar`.
  `application-dev.yml` dùng chung `INTERNAL_API_KEY` dev với shop-service.
